# 暖言聊天自动回复助手

面向 Windows 桌面版 QQ 与微信的一对一聊天自动回复工具。公开版只使用在线文本模型生成回复，当前固定接入 DeepSeek API；每位使用者必须填写自己的 API Key。

> 当前是早期公开版。聊天客户端更新可能导致窗口识别失效；自动化操作也可能触发平台限制。请只在账号本人控制、聊天对象知情同意的情况下使用，禁止用于批量营销、骚扰、冒充、欺诈或绕过平台风控。

## 功能

- 在 QQ 或微信中锁定一个联系人，避免误发给其他会话。
- 合并对方连续来信后统一生成回复，并在发送后补查遗漏消息。
- 区分对方消息与自己发送的内容，降低重复回复风险。
- 按双方关系、使用者性别和可选背景调整语气。
- API Key 使用 Windows DPAPI 加密，并保存在当前用户的应用数据目录。
- 提供托盘运行和 `Ctrl+Alt+Q` 紧急停止。

## 环境

- Windows 10/11
- Python 3.12
- 已登录的桌面版 QQ 或微信
- DeepSeek API Key

现代微信窗口的后台画面读取和图片/表情理解仍可选用本机 Ollama `qwen2.5vl:3b`。它只负责视觉识别，不生成聊天回复，也不随仓库分发。未安装时，QQ 的普通文字聊天仍可使用；部分微信版本和纯图片消息可能无法识别。

## 下载运行

不想配置 Python 的用户可前往 [Releases](https://github.com/JashinYang/nuanyan-chat-auto-reply/releases) 下载 `nuanyan-chat-auto-reply-v0.1.1-Windows-x64.zip`，解压后运行 `暖言聊天自动回复助手.exe`。当前安装包尚未进行商业代码签名，Windows 首次运行时可能显示安全提醒；请核对同页 `SHA256SUMS.txt` 后再运行。

## 从源码运行

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

首次启动后，选择聊天软件和联系人，填写双方关系、你的性别及自己的 API Key，然后先使用“测试 AI”和“检查 QQ/微信”。

## 隐私与安全

- 在线模型生成回复时，当前待回复文字、有限聊天上下文和使用者填写的关系信息会发送给固定的 DeepSeek API；截图不会发送给 DeepSeek。
- 使用者必须提供自己的 DeepSeek API Key，并自行负责账户、调用费用、输入内容及服务条款。本项目不会提供或代理公共 Key。
- API Key 通过 Windows DPAPI 加密，保存在当前用户的 `%APPDATA%\暖言聊天助手公开版`；公开版使用独立配置目录，不覆盖私有版设置。
- 本程序不主动收集或上传遥测、联系人列表、截图、聊天记录或日志。完整说明见 [PRIVACY.md](PRIVACY.md)。
- 不要把 API Key、聊天记录、日志、截图、Cookie、Token 或应用数据目录提交到仓库或公开 Issue。
- 遇到人身安全、暴力、急症或敏感金钱主题时，程序会停止自动回复并提示本人接管。

## 已知限制

- QQ/微信更新、窗口缩放、主题和辅助功能树变化都可能影响识别。
- 微信后台读取属于实验功能，不保证适配所有客户端版本。
- 当前只支持一个锁定联系人，不适合群发或无人值守运营。
- 当前安装包没有代码签名，Windows SmartScreen 可能显示提醒。
- 使用者必须遵守 QQ、微信的软件许可协议及平台规则；桌面自动化可能导致功能限制、账号风控或封禁。
